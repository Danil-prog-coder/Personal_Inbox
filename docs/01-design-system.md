# Personal Inbox — дизайн-система (Liquid Glass)

> **Источник правды — `docs/reference/reference-source.html`.**
> Этот документ его пересказывает. При любом расхождении прав референс.
> Все значения ниже извлечены из референса дословно, не «на глаз».

Готовые CSS-переменные и рецепты: **`docs/reference/design-tokens.css`** — подключать
как есть, значения не редактировать.

---

## 1. Железные правила

1. **Ни одного захардкоженного цвета.** Только `var(--...)` из `design-tokens.css`.
   Единственное исключение — четыре цвета важности и градиенты источников, которые
   тоже вынесены в токены.
2. **Каждая тема проверяется отдельно.** Тёмная и светлая — не «инверсия», у них
   разные градиенты фона и разные текстовые оттенки уровней.
3. **Стекло = четыре свойства вместе**, всегда одним блоком:
   `background: var(--glass)` + `backdrop-filter: blur(N) saturate(200%)` +
   `border: 1px solid var(--stroke)` + `box-shadow: inset 0 1px 0 var(--hi), var(--sh2)`.
   Убрать любое из четырёх — стекло превращается в серый прямоугольник.
   `-webkit-backdrop-filter` дублируется всегда.
4. **Под экраном устройства лежат отдельные обои.** Панелям нужно что преломлять:
   если фон под стеклом однотонный, эффект пропадает.
5. **Шрифт один — системный.** `system-ui, -apple-system, "SF Pro Text", "Segoe UI", sans-serif`.
   Веб-шрифты не подключаются.
6. **Скруглений три группы**, промежуточных значений не изобретать:
   карточки 22–26px, листы и модальные 26–34px, контролы-пилюли `999px`.

## 2. Цвета важности

Единственное место в интерфейсе с насыщенным цветом.

| Уровень | Чистый цвет | Иконка | Подпись |
| --- | --- | --- | --- |
| `CRITICAL` | `#ff4a3d` | треугольник (`warn`) | Критично |
| `HIGH` | `#ff9f0a` | молния (`bolt`) | Важно |
| `NORMAL` | `#0a84ff` | точка (`dot`) | Обычное |
| `LOW` | `#98a2b3` | часы (`clock`) | Неважно |

**Цвет никогда не идёт один.** Всегда цвет + иконка + подпись — уровень читается
и без различения оттенков (дальтонизм, монохромный экран).

Чистый цвет — для боковой грани карточки, точек, полос распределения и свечения.
Для **текста** уровня — отдельные читаемые оттенки: `--crit-ink`, `--warn-ink`,
`--info-ink`, `--mute-ink` (в светлой теме они темнее, чтобы держать контраст).

Чип уровня: `background: var(--lvl-*-bg)`, `border: 1px solid <чистый цвет>44`,
`color: var(--*-ink)`, `font: 600 11.5px/1`, `padding: 4px 10px 4px 8px`, `border-radius: 999px`.

Боковая грань карточки — та деталь, ради которой уровень не занимает места в контенте:
```css
position: absolute; left: 0; top: 14px; bottom: 14px;
width: 3px; border-radius: 0 3px 3px 0;
background: <чистый цвет>; box-shadow: 0 0 12px <чистый цвет>99;
```

## 4. Линза — главный жест

Один переиспользуемый компонент, **не четыре разных**. Применяется в четырёх местах:

1. Таб-бар на телефоне
2. Боковая навигация на десктопе
3. Переключатель периода в сводке
4. Переключатель уровня важности в деталях сообщения

Стеклянный прямоугольник переезжает к выбранному элементу за **0.48s**
с пружинным замедлением `cubic-bezier(.32, 1.5, .4, 1)`, пока подписи меняют цвет
за `0.32s cubic-bezier(.4, 1.1, .4, 1)`.

**Ширина линзы вычисляется, а не задаётся:** `calc((100% - 8px) / N)`, сдвиг —
`translateX(calc(<индекс> * 100%))`. При любом числе кнопок линза точно совпадает
с элементом. Хардкод ширины — ошибка, которую сразу видно при 3 vs 4 сегментах.

Рецепт целиком — класс `.lens` в `design-tokens.css`.

## 5. Остальное движение

| Что | Длительность | Кривая | Анимация |
| --- | --- | --- | --- |
| Появление контента раздела | 0.34s | `cubic-bezier(.2,.9,.3,1)` | `glassIn` (подъём на 14px + scale .985) |
| Лист / модальное окно | 0.34–0.38s | та же | `glassIn` |
| Новое сообщение в ленте | 0.5s | `cubic-bezier(.2,1.2,.3,1)` | `dropIn` (сверху, -18px) |
| Смена темы (фон) | 0.5s | `ease` | — |
| Карточка источника под курсором | 0.2s | — | подъём |
| Нажатие кнопки | 0.18s | `cubic-bezier(.3,1.4,.4,1)` | `translateY(1px) scale(.985)` |
| Скелетон загрузки | — | — | `shimmer` |
| Индикатор обработки | — | linear | `spin` |
| Декоративное пятно на входе | 9s infinite | `ease-in-out` | `floaty` |

Движение подчинённое: главный жест один, остальное его не перебивает.

## 6. Типографика

Все значения — из референса.

| Роль | Правило |
| --- | --- |
| Заголовок экрана входа | `600 clamp(30px, 4vw, 40px)/1.08`, `letter-spacing: -.03em` |
| Логотип-надпись | `600 14px/1`, `letter-spacing: .16em`, `text-transform: uppercase`, `--ink3` |
| Заголовок раздела | `600 15px/1`, `letter-spacing: -.01em` |
| Тема сообщения | `520 15px` обычное / `600` непрочитанное |
| Имя отправителя | `600 13px/1.2` |
| Адрес, время | `400 11.5px/1.2`, `--ink3` |
| Сниппет | `400 13px/1.5`, `--ink2`, `-webkit-line-clamp: 3` (в компактном режиме — 1) |
| Чип, бейдж, метаданные | `600 11.5px/1` |
| Подпись поля ввода | `500 11.5px/1`, `letter-spacing: .05em`, uppercase, `--ink3` |

`--ink3` (третичное). Четвёртого не заводить.

## 7. Иконки

Только инлайновый SVG, `viewBox="0 0 24 24"`, `fill: none`, `stroke: currentColor`,
`stroke-width: 1.7`, `stroke-linecap: round`, `stroke-linejoin: round`.
Иконочные библиотеки не подключаются.

Полный набор из 17 путей — в референсе (`icon()` в `reference-source.html`):
`feed`, `summary`, `connections`, `settings`, `search`, `filter`, `back`, `close`,
`bolt`, `reply`, `clock`, `ext`, `chev`, `warn`, `check`, `plus`, `dot`.
Скопировать `d`-атрибуты дословно.

Размеры: навигация 21px (телефон) / 17px (десктоп), шапка 15–17px, метаданные 12px.

## 8. Аватары

38×38px, `border-radius: 13px`, инициалы `600 13.5px/1` белым.
Заливка выбирается **детерминированно из имени отправителя**, чтобы один человек
всегда был одного цвета:
```js
let hash = 0;
for (const ch of from) hash = (hash * 31 + ch.charCodeAt(0)) % 997;
const bg = AVATARS[hash % AVATARS.length];
```
Палитра из шести градиентов — в референсе (`AV`).

Бейдж источника: 17×17px, `border-radius: 6px`, в правом нижнем углу со сдвигом -4px,
`box-shadow: 0 0 0 2px rgba(0,0,0,.28), inset 0 1px 0 rgba(255,255,255,.45)`,
буква `700 8px/1` белым: `M` для Gmail, `T` для Telegram.

## 10. Доступность

- Контраст текста к стеклу — минимум 4.5:1 в **обеих** темах. Светлая тема проверяется
  отдельно: `--ink2` там `rgba(11,18,34,.68)`, не белый с прозрачностью.
- Уровень важности всегда дублируется иконкой и подписью, не только цветом.
- Все интерактивные элементы — `<button>` / `<a>`, не `<div onClick>`.
- Видимый фокус клавиатуры: `outline: 2px solid var(--accent); outline-offset: 2px`.
- Цель нажатия на телефоне — минимум 44×44px.
- `@media (prefers-reduced-motion: reduce)` — все `transition` и `animation`
  сокращаются до `0.01ms`, линза переставляется мгновенно.

## 11. Чек-лист перед тем, как считать UI-задачу сделанной

- [ ] Открыл `docs/reference/reference-source.html` и сверил компонент с оригиналом
- [ ] Ни одного цвета мимо `design-tokens.css`
- [ ] Проверено в тёмной теме
- [ ] Проверено в светлой теме
- [ ] Проверено на ширине телефона (`< 900px`)
- [ ] Проверено на ширине десктопа (`>= 900px`)
- [ ] У стекла все четыре свойства, включая `-webkit-backdrop-filter`
- [ ] Скругления попадают в одну из трёх групп
- [ ] Уровень важности показан цветом + иконкой + подписью
- [ ] Линза (если есть) считает ширину, а не хардкодит
- [ ] `prefers-reduced-motion` учтён
